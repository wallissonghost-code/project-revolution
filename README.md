# Project Revolution — Alpha 0.1

Protótipo mobile-first de mundo aberto 3D com Three.js, TypeScript e Vite.

## Rodar

```bash
npm install
npm run dev
```

## Validar

```bash
npm test
npm run build
```

## Escopo

Cidade fictícia simples, personagem em terceira pessoa, câmera touch, joystick, corrida, salto e colisões. Multiplayer e governo são etapas futuras.
